Gesture-Controlled Tic-Tac-Toe with AI Bot

Built an interactive Tic-Tac-Toe game supporting both webcam gesture controls and manual mouse clicks. The project features an AI opponent with three difficulty levels: Easy (randomized moves), Normal (balanced strategy), and Hard (optimal play via Minimax). It demonstrates computer vision, real-time hand gesture recognition, and AI gameplay in a user-friendly interface with instant win/draw detection.

Live project demo

VOOP – Smart Assistive Spectacles for the Visually Impaired

VOOP is an AI-powered smart spectacle that helps visually impaired users navigate safely and independently using advanced sensors, camera vision, and offline processing. It combines voice guidance with an 8-zone haptic vibration system to communicate obstacles, directions, and environment data without relying solely on audio. The project also includes fall detection, emergency SOS calling, GPS-based navigation, OCR text reading, bone-conduction audio, and a lightweight 47-gram wearable frame.
